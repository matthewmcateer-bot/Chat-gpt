# First audition: Field Organism preview 0.1
This is a control-device prototype derived from IRREDUCIBLE_v0_2.scd.
It adds weighted breath rates, rare flurries propagating through fracture/motion/energy, and slow thinning.
It does not port the sine bank, Doppler, Shepard layer or frequency relocation DSP.
Load one Conductor only: both versions broadcast on EP_FIELD.
Place this audio effect in a Set containing Emergent Properties devices. Switch RUN on; start Intensity at 0.35.
For audible self-generated material, enable RUN on Resonant Matter separately.
Other effects need incoming audio: route Tracker, DeepMind or 0-Coast through your audio interface to an audio track with monitoring enabled, then add the effects.
Try Resonant Matter -> Spectral Lattice -> Parallax first; introduce memory effects later.
Hold freezes this variant's evolving controls; it does not mute audio. RUN off stops evolution.
A lower energy control changes density/energy mappings, not the entire Set's master volume.
