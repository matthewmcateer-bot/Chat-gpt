# Tracker project briefs

All seven are concepts, not built Tracker projects.

## Mnemonic Receiver
Speech fragments emerge from six granular voices; E minor with a separately selected G-sharp memory colour.

## False Memory Choir
One source becomes a choir; retain E and B while exchanging G and G-sharp, avoiding unwanted simultaneous thirds.

## Parallel-Fifth Weather
Move E-B, G-D, A-E, C-G and D-A pairs through registers; DeepMind shadows the pairs.

## Eight Haunted Rooms
Pattern banks change source-region and filter identity; short shared samples keep memory bounded.

## Collapse and Return
Long sparse form, density accumulation, an intentional rest and a displaced return of the motif.

## Spectral Doppelganger
DeepMind chords recall the granular harmony late; sparse 0-Coast motif fragments use a separate MIDI channel.

## Radio Oracle
Offline crop/tune/level workflow generates a fresh project from each new recording; validate before SD deployment.
